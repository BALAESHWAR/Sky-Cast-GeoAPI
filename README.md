# 🌦 Sky Cast GeoAPI App

A modern, responsive weather web application that fetches and displays real-time weather data using a public API. The application automatically detects the user’s current location and also allows searching for cities with smart autocomplete suggestions.

---

## ✨ Features

- 📍 Auto-detects user location using Geolocation API
- 🔍 City search with autocomplete suggestions
- 🌡 Displays current temperature and weather conditions
- 🌬 Shows wind speed and basic weather details
- 📅 7-day weather forecast
- ☀️ Weather icons based on conditions
- 📱 Fully mobile-responsive UI
- 🔓 No API key or signup required

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page  
- **CSS3** – Styling and responsive layout  
- **JavaScript (Vanilla JS)** – Logic, API handling, DOM manipulation  
- **Open-Meteo API** – Public weather and geocoding API  

---

## 🌍 APIs Used

- Weather Forecast API: https://open-meteo.com/
- Geocoding API: Open-Meteo Geocoding API

> This project uses public APIs and does not require any authentication or API key.

## 🚀 How to Run the Project

### Option 1: Run Locally
1. Download or clone the repository
2. Open the folder in VS Code
3. Open `index.html` in any modern web browser

### Option 2: Using Live Server (Recommended)
1. Install **Live Server** extension in VS Code
2. Right-click `index.html`
3. Click **Open with Live Server**
